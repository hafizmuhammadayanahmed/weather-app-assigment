# SkyCast Weather App

A responsive weather app built with **HTML, CSS and JavaScript**.

## Features
- Search weather by city
- Current temperature, feels-like temperature and conditions
- Humidity, wind speed, pressure and cloud cover
- Today's high and low
- Responsive mobile and desktop layout
- Loading and error messages
- No API key required (Open-Meteo)

## Run locally
Open `index.html` in your browser. For a local development server, use VS Code Live Server.

## Deploy to Vercel
1. Push this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Framework preset: **Other**; Build Command: leave blank; Output Directory: `.`.
4. Click Deploy.

## APIs
- Open-Meteo Geocoding API
- Open-Meteo Forecast API
